Featured Projects

I-80 Donner Pass Closure Risk Dashboard Live Dashboard

Python · scikit-learn · AWS Lambda · S3 · Weather APIs · Machine Learning

Built a machine-learning risk-ranking system for I-80 near Donner Pass using hourly weather data and manually reviewed closure records. The model predicts 24-hour closure risk and publishes Low / Medium / High / Extreme risk results to an S3-backed dashboard.

  • Engineered weather-based features from hourly forecast and historical weather data.
  • Trained and compared logistic regression, random forest, and gradient boosting models.
  • Validated performance using chronological winter splits to avoid time leakage.
  • Deployed an AWS Lambda pipeline that saves raw weather, risk history, and latest dashboard JSON to S3.
  • Built a dashboard page to display the latest model risk level and supporting weather context.

Operations Analytics: Forecasting Attendance at a Regional Waterpark
